# Günlük Planlayıcım

React + Vite ile hazırlanmış, görev ekleme/listeleme/güncelleme/silme özelliklerine sahip basit bir günlük planlayıcı.

## Gereksinimler
- Node.js'in güncel LTS sürümü
- Visual Studio Code
- İnternet bağlantısı (ilk kurulumda paketler ve Google Fonts için)

## Kurulum
1. Bu klasörü Visual Studio Code ile aç.
2. Terminal > New Terminal menüsünü aç.
3. Şu komutu çalıştır: `npm install`
4. Kurulum bitince: `npm run dev`
5. Terminalde görünen yerel adresi (genellikle `http://localhost:5173`) tarayıcıda aç.

## Özellikler
- Görev ekleme
- Görevleri listeleme
- Görev metni, kategori ve önceliği güncelleme
- Görev silme (onay sorar)
- Görevi tamamlandı/tamamlanmadı olarak işaretleme
- Tümü, devam edenler ve tamamlananlar filtreleri
- Tarayıcının LocalStorage alanına kaydetme

## Teslim öncesi
